
## Dataset

This project uses a three-class image dataset consisting of cats, dogs, and pandas. Each class contains at least 25 images collected from publicly available online image sources.

The raw dataset is not included in this repository because its size exceeds the recommended repository limit. To recreate the dataset, create an `images/` folder with three subfolders (`cats`, `dogs`, and `pandas`) and place at least 25 images in each folder.

Folder structure:

images/
├── cat/
├── dog/
└── panda/
